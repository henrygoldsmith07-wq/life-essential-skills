# Content-quality checklist

[Contributing](CONTRIBUTING.md) · [Mastery](curriculum/mastery.md) · [Source register](RESOURCES.md)

## Learning and assessment

- [ ] The goal names an observable action.
- [ ] The lesson stays short and practical.
- [ ] The domain criterion matches the scenario rubric and structured index.
- [ ] The task tests calculation, judgement, verification, or action beyond simple recall.
- [ ] Context and materials contain enough information, or explicitly identify missing facts.
- [ ] The suggested explanation is hidden and calculations are checked independently.
- [ ] Guided practice, independent demonstration, hands-on evidence, and retention stay distinct.
- [ ] A fresh reassessment and useful next skill are available.

## Scope and accessibility

- [ ] People, documents, rates, and scenarios are fictional or clearly sourced.
- [ ] Personal/sensitive information is absent.
- [ ] No exercise requires real payment, hazardous action, or treatment change.
- [ ] High-stakes guidance uses appropriate current sources and professional limits.
- [ ] Jurisdiction is explicit; England and Wales guidance is not conflated.
- [ ] Plain language, accessible response formats, and reasonable adaptations are supported.
- [ ] Civic content explains official processes without political advocacy.
- [ ] No invented statistics, guaranteed outcomes, duplicated filler, or unnecessary infrastructure.

## Repository maintenance

- [ ] Navigation and internal links work.
- [ ] Metadata and source dependencies are updated together.
- [ ] Source dates reflect actual review and withdrawn guidance is replaced.
- [ ] Checks pass; blocked external sources are disclosed as unverified.
- [ ] Changelog and affected pathways are updated where useful.
