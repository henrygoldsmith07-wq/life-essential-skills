# Progress: demonstrations and retained ability

[Mastery rules](../curriculum/mastery.md) · [Diagnostic](../curriculum/diagnostic.md) · [Assessment record](assessment-record.md)

Copy into `personal/progress.md` locally. Record one row per competency attempt, not one confidence score per domain. Use exact IDs from the [domain map](../curriculum/dependency-map.md). Keep actual personal records securely outside GitHub.

If a wide table is difficult to use, keep one compact [assessment record](assessment-record.md) per attempt instead. It captures the same evidence in short fields.

## Learning activity

| Competency | Read date | Understood: explanation/evidence | Practised date/task | Demonstrated independently: date/evidence | Retained later: date/evidence |
| --- | --- | --- | --- | --- | --- |
| | | | | | |

These are distinct states. A read page is not a demonstration. Retention requires a fresh delayed task, not recalling the published answer.

## Assessment and review log

| Competency | Mastery stage assessed | Date practised | Scenario/capstone or fresh task | Evidence of demonstration | Help/checklist needed | Result: met / assisted / not yet | Next review date | Spaced reassessment: date/result/evidence | Next recommended skill |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | | | |

Use Foundation, Applied, Independent, or Advanced scenario. For reassessment, record retained / needed help / not retained. Add attempts rather than overwriting history. Record practical actions separately where required; a written plan cannot replace them.
