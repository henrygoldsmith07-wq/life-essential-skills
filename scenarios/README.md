# Scenario library

[Curriculum](../README.md) · [Diagnostic](../curriculum/diagnostic.md) · [Capstones](../capstones/README.md)

Read the situation, produce a response, and only then open the hidden explanation. The library uses fictional documents to test judgement, calculations, verification, and action. A good answer explains what you would do and why; it does not merely name the right topic.

Use the same scenario with a checklist for an Applied attempt and without prompts for an Independent attempt. An Advanced scenario attempt must also handle the variation. Do not reuse a memorised solution as independent evidence: use the [reassessment cards](../curriculum/reassessment.md), change the materials, or ask a partner for a fresh variation. Record performed practical tasks separately.

For emergencies, health, wellbeing, and safety, assess planning and verified help routes only. Actual physical first aid requires recognised practical assessment. You may use fictional details and skip a distressing scenario in favour of a neutral equivalent.
