# Use your learner dashboard

Start with **Today**, choose your locality and pathway in **My setup**, and try the recommended fictional diagnostic. Use **Learn the skill** when a step is unfamiliar. Complete a response before opening feedback, compare it with the criteria, and save educational evidence. Your next recommendation changes with that evidence.

**Progress** separates knowledge, independent judgement, help and delayed checks. **Practice** offers fresh scenarios and existing capstones. **Pathways** keeps learning relevant to independent living, money/admin, digital safety, school to work or a general foundation. No attendance streak, XP or ranking is used.

Your response is temporary; only bounded educational evidence is saved in this browser. Download a local backup if useful. Use fictional data and never enter passwords, account details, identity documents, medical records or private contacts. Accessible response formats do not reduce the rating.

Serve the repository root over HTTP, then open `/learner/`. A maintainer can run `python -m http.server 8000 --bind 127.0.0.1` and open `http://127.0.0.1:8000/learner/`. Directly opening an HTML file cannot reliably load feedback. No framework, login or server-side learner database is needed.

The [text start guide](../START-HERE.md) and [text diagnostic](../curriculum/diagnostic.md) remain available. For maintainer details, use the separate [architecture guide](../docs/architecture.md).
