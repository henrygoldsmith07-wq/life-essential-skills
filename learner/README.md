# Use your learner dashboard

Start with **Today**, choose your locality and pathway in **My setup**, and try the recommended fictional diagnostic. Use **Learn the skill** when a step is unfamiliar. Complete a response before opening feedback, compare it with the criteria, and save educational evidence. Your next recommendation changes with that evidence.

For every criterion, choose **met**, **partly met** or **not met** for your original answer. The result follows these judgements, help and errors; you cannot choose a final success label. Self-review is not independent verification. Opening feedback makes that material familiar even if you close without saving.

**Progress** shows self-reviewed and assessor-reviewed evidence, help, later checks, practical checks still needed and next steps. **Practice** starts with recommended tasks; choose needs work, review due, fresh tasks, guided practice or capstones, then filter/search by skill. Familiar material is useful practice and cannot prove fresh transfer. Capstones save results per skill, not a whole-domain award. **Pathways** keeps learning relevant to your goals. No attendance streak, XP or ranking is used.

**Assessor** lets someone review an existing original performance privately, add a separate review, or record a permitted safe practical observation. Download the updated local file to keep it. The original answer and assessor identity are never saved. Local labels are declarations, not authenticated certificates.

Your response is temporary; only bounded educational evidence is saved in this browser. Download a local backup if useful. Use fictional data and never enter passwords, account details, identity documents, medical records or private contacts. Accessible response formats do not reduce the rating.

Serve the repository root over HTTP, then open `/learner/`. A maintainer can run `python -m http.server 8000 --bind 127.0.0.1` and open `http://127.0.0.1:8000/learner/`. Directly opening an HTML file cannot reliably load feedback. No framework, login or server-side learner database is needed.

The [text start guide](../START-HERE.md) and [text diagnostic](../curriculum/diagnostic.md) remain available. For maintainer details, use the separate [architecture guide](../docs/architecture.md).
